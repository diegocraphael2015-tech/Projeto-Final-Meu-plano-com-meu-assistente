# Projeto-Final-Meu-plano-com-meu-assistente
Este projeto foi desenvolvido como parte do Projeto Final da Trilha de Inteligência Artificial.  A proposta é criar um assistente de planejamento utilizando o Notion e o ChatGPT, capaz de ajudar na organização e execução de objetivos de diferentes áreas, como estudos, carreira e negócios.
